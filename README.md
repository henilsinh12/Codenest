# CodeNest — Learn to Code, Build Your Future 🚀

CodeNest is a modern, responsive landing page for an online coding education platform designed to help students and beginner programmers develop their programming skills through practical learning and structured learning paths.

The project focuses on clean UI/UX design, responsive layouts, reusable components, and a consistent visual experience across desktop and mobile devices.

## 🌐 Project Links

- **Live Website:** [CodeNest](https://henilsinh12.github.io/Codenest/)
- **GitHub Repository:** [Codenest](https://github.com/henilsinh12/Codenest)
- **Figma Design:** [Open in Figma](https://www.figma.com/design/91bSkR9Eh3XrEEMWJsUtWW/CodeNest?node-id=12-474)

## 🎯 Target Audience

CodeNest is designed for:

- Students who want to learn programming.
- Beginners starting their coding journey.
- Self-learners looking for structured learning paths.
- Aspiring developers who want practical project experience.

## ✨ Features

- **Responsive Design:** Adapts the layout to different screen sizes.
- **Navigation Header:** Provides access to the main sections and call-to-action.
- **Hero Section:** Introduces the platform with a headline, description, and primary button.
- **Feature Cards:** Highlights the key benefits of learning with CodeNest.
- **Learning Paths:** Presents learning options in an organized layout.
- **Testimonial Section:** Adds a learner-focused element to the page.
- **Call-to-Action Section:** Encourages visitors to start learning.
- **Footer:** Completes the landing page layout.
- **Interactive Navigation:** JavaScript supports the navigation interactions implemented in the project.

## 🎨 UI/UX Design

The CodeNest landing page follows a clean, modern, education-focused design.

### Design Principles

- Clear visual hierarchy.
- Consistent spacing and alignment.
- Readable typography.
- Consistent colors and visual styles.
- Reusable UI components.
- Clear call-to-action buttons.
- Responsive layouts for desktop and mobile screens.

### Design Documentation

The repository includes design documentation in the `docs/` directory:

## 💻 Run Locally

To run the project on your computer:

1. Clone the repository:

   ```bash
   git clone https://github.com/henilsinh12/Codenest.git
   ```

2. Open the project directory:

   ```bash
   cd Codenest
   ```

3. Open `index.html` in your web browser.

   Alternatively, open the project in Visual Studio Code and use the Live Server extension.
