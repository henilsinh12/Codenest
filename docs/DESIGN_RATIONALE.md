# Design rationale — CodeNest

CodeNest is a fictional learning platform for students, beginners, and early-career learners who want to learn technology by building projects.

The page uses a strong hero heading, concise supporting copy, and two clear calls to action to communicate the product quickly. The code-editor illustration makes the platform's subject immediately recognizable. Three feature cards explain the core value proposition: practice, build real projects, and grow confidence. Learning-path cards offer a concrete next step. The student testimonial adds social proof, while the final CTA gives the page a clear ending.

Purple is the primary brand color because it feels creative and modern. Soft lavender surfaces keep the interface approachable; dark navy text supports readability; green is reserved for success and positive states. Typography uses a simple Inter hierarchy, and spacing follows a consistent 4 px scale.

The desktop design uses a centered content width and three-column card rows. The mobile design stacks content vertically, keeps buttons and text legible, and replaces desktop navigation with a menu icon. The layouts are intended to be rebuilt with Figma Auto Layout rather than treated as flattened artwork.
